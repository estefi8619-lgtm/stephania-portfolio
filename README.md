# Portafolio de Stephania Gonzalez Mur — Unity & C#

Sitio web estático bilingüe (español/inglés), con estética oscura en morados y acentos magenta/rosa. Está hecho con HTML, CSS y JavaScript; no necesita instalar dependencias ni compilar.

## Ver localmente
1. Extrae el ZIP.
2. Abre `index.html` en un navegador actualizado.
3. Usa el selector ES / EN para cambiar el idioma.

## Contenido incluido
- Presentación profesional y secciones de proyectos, sobre mí, habilidades y contacto.
- Proyecto Helenia con tres capturas reales del prototipo.
- Detalles técnicos desplegables sobre mecánicas, IA de enemigos, UI, controlador e integración de recursos.
- Wireframe de planificación de la interfaz que se puede ampliar.
- Botón de CV diseñado y funcional como aviso temporal. Cuando el PDF esté listo, se podrá conectar al archivo real.
- Enlaces de correo, LinkedIn e itch.io.

## Antes de publicar
- Añade el PDF final del CV y cambia el botón temporal para abrirlo o descargarlo.
- Confirma los créditos y las licencias de los recursos externos antes de añadir capturas o imágenes que los contengan.
- Revisa el sitio en escritorio y móvil.

## Publicar con GitHub Pages
1. Crea un repositorio público separado para la web del portafolio.
2. Sube el contenido de esta carpeta al directorio raíz del repositorio.
3. En GitHub, abre **Settings → Pages** y selecciona la rama que contiene `index.html` y la carpeta raíz.
4. Guarda los cambios y espera a que GitHub Pages publique el sitio.

Los repositorios privados de tus proyectos de juego no necesitan hacerse públicos para publicar esta web.
